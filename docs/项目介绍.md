# 流萤音乐 · 项目介绍

## 一、项目介绍

### 1. 项目定位

**流萤音乐（Liuying Music）**是一个个人全栈音乐产品：**双端原生客户端（iOS + Android）+ 自建后端 + 自建音源桥 + H5 管理后台/官网** 的一体化工程，覆盖「听歌 → 推荐 → 互动 → 上传 → 管理」完整链路，从音源采集到客户端播放全链路自持，无第三方 SaaS 依赖。

### 2. 项目形态

| 组件 | 技术 | 说明 |
|---|---|---|
| iOS 客户端 | SwiftUI + AVQueuePlayer + AVAudioEngine | iOS 16.0+，Bundle ID `app.star2936.guava3291` |
| Android 客户端 | Kotlin + Jetpack Compose + Media3 ExoPlayer | minSdk 29 / targetSdk 35，包名与 iOS 一致 |
| 后端服务 | Python 标准库（无框架） | 端口 8788，SQLite 存储，HTTP 路由 + WebSocket |
| 音源桥 | NodeJS（bridge.js） | 端口 8789，长青音源 + 汽水音乐解析 + 兜底聚合 |
| GM 兜底音源 | Python 服务 | 端口 18080，音源兜底 |
| 管理后台 | H5（server/templates/admin.html） | 用户/歌曲/评论/公告/轮播图/网站管理/AI 乐评配置 |
| 官网落地页 | H5 静态页（web/） | 产品介绍 + 扫码下载（安卓/iOS） |
| 部署 | Nginx 反代 + systemd | 安装向导一键部署（install/） |

### 3. 架构与数据流

```
┌─────────────┐   HTTPS /api/*    ┌──────────────────────────────┐
│ iOS App     │ ────────────────▶ │ Nginx 反代 (443)              │
│ (SwiftUI)   │ ◀──────────────── │   /music/ → 后端 8788         │
└─────────────┘   206 流式音频    │   /music/api/ws → WS Upgrade  │
                                  │   /s/ 短链 → 分享页            │
┌─────────────┐   HTTPS /api/*    │                              │
│ Android App │ ────────────────▶ │   / 官网 → web/               │
│ (Compose)   │ ◀──────────────── │                              │
└─────────────┘   签名流 URL      └──────────┬───────────────────┘
                                             │
                                  ┌──────────▼───────────────────┐
                                  │ 后端 server/ (8788)           │
                                  │  handler/main/common/media    │
                                  │  recommend(个性化) ws(推送)    │
                                  │  database(SQLite)             │
                                  │  qishui(汽水解析) templates(H5)│
                                  └───────┬──────────┬────────────┘
                                          │ 采集/落库  │ 解析请求
                               ┌──────────▼───┐   ┌───▼────────────┐
                               │ 音源桥 (8789) │   │ GM 兜底 (18080) │
                               │ bridge.js     │   │ 兜底音源服务     │
                               │ 长青/汽水/聚合  │   └────────────────┘
                               └──────────────┘
```

**核心链路**：
- **播放**：客户端 → 后端 `stream-url/{id}` 签发带 `exp+sig` 的签名 URL → `/stream/{id}` 206 分片流式播放（防盗链、支持 `br=96` 低码率懒转码回退）
- **个性化推荐**：多路召回（行为 × 场景 × 新鲜度）→ 融合打分 → MMR 去重 → 端上竖滑无限流（队尾续播）
- **实时通知**：WebSocket（Nginx Upgrade 透传）推送 like/comment/share/follow/官方通知 → 客户端红点 + 列表即时刷新；行为数据走 WS 上行、断线回退 HTTP
- **音源采集**：音源桥解析长青音源/汽水音乐分享 → 采集脚本落库（`collected_tracks`）→ 转码（原码率/96k 懒转码）
- **AI 乐评**：后台配置大模型 Key → 定时主动评论（可带网络热梗 / 表情包图片），乐评账号名称/头像/签名可配置

### 4. 功能矩阵（iOS / Android 双端对齐）

| 功能域 | 能力 |
|---|---|
| 播放 | 竖滑切歌（VerticalPager）、三种播放模式、听歌模式（默认/我的作品/我的喜欢/新鲜）、汽水式无限流、队列修剪、播放会话持久化 |
| 歌词 | KRC/LRC 逐字歌词（卡拉OK 填充）、播放页两句预览、全屏歌词（iOS 3D / Android 基础版） |
| 发现 | 猜你喜欢（个性化 × 天气时段场景融合）、最新上架、全部歌曲、天气卡片（后台异步加载 + 「仅时段」兜底） |
| 我的 | 作品/喜欢/评论三 Tab、累计听歌时长、背景图沉浸式头部、粉丝/关注/互关统计 |
| 消息 | 互动通知分页（加载更多）、官方消息、WebSocket 实时红点、软删除 |
| 互动 | 点赞/评论（支持图片评论、评论点赞）/分享短链/关注 |
| 侧边栏 | 听歌模式切换、场景音乐 12 宫格、无作品时隐藏「我的作品」 |
| 用户体系 | 注册/登录（加密存储）、多账号切换、资料编辑（头像/背景/签名/性别/年龄）、用户主页 |
| 上传 | 歌曲 + 封面上传（后端魔数校验、封面压缩、转码） |
| 弱网 | 200MB LRU 流缓存、小缓冲快起播 + 大缓冲抗抖、15s 卡死自愈、网络错误自动重试、解码错误跳歌 |
| 音效 | iOS：引擎音效（3D/360/复古/现场/流行/摇滚，缓存共享）；Android：系统均衡器近似 |
| 系统 | 更新弹窗（forceUpdate 强制）、公告（showOnce 去重）、锁屏/通知栏媒体控制 |

### 5. 部署与运维形态

- **部署**：`install/` H5 向导一键安装（检测 → 备份 → 配置 → 建库 → systemd 服务 → 自检 → 回滚）；Nginx 反代 + 站点 `www.dbmt999.asia`
- **升级**：`deploy.py` 上传单文件到服务器 + 重启对应服务；后端/音源桥/官网各自独立更新
- **CI**：GitHub Actions 构建 iOS（xcodegen + xcodebuild），产物归档
- **数据**：SQLite（tracks/collected_tracks/users/behavior_events/play_history/notifications 等），行为数据清理脚本留备份
- **监控**：服务自检接口、日志（`server/` 运行日志、`source-bridge/collect_v3.log`）
